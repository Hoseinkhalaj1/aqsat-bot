# راهنمای ربات

## منوی اصلی

| دکمه | کار |
|---|---|
| 📊 داشبورد | بدهی باقیمانده، وضعیت ماه، معوقه‌ها، پرداخت‌های پیش رو و پیشرفت وام‌ها |
| 📅 این ماه | همه پرداخت‌های ماه با دکمه ثبت پرداخت؛ جابه‌جایی بین ماه‌ها |
| ➕ افزودن | ویزارد افزودن وام/قسط، پرداخت دوره‌ای یا یک‌باره |
| 📋 لیست من | موارد فعال و بایگانی با فیلتر نوع |
| 💵 درآمد و برنامه | درآمدهای ثابت، برنامه تخصیص، آمار درآمدها و پیش‌بینی |
| 📈 گزارش‌ها | گزارش ماهانه و سالانه، خروجی اکسل |
| 🗂 دسته‌بندی‌ها | مدیریت دسته‌ها و سقف بودجه ماهانه |
| ⚙️ تنظیمات | زمان و ساعت یادآوری‌ها |
| 🛠 مدیریت | (فقط مدیر) کاربران، آمار، بکاپ فوری، پیام همگانی |

دستورها: `/start`، `/menu`، `/cancel` (لغو عملیات جاری)، `/id` (نمایش شناسه).

## افزودن قسط

**🏦 وام / قسط** — عنوان ← دسته ← طرف حساب ← تعداد اقساط ← نحوه مبلغ ← تاریخ اولین قسط ← فاصله ← (اگر تاریخ گذشته است) تعداد اقساط پرداخت‌شده ← مشترک بودن ← تأیید

نحوه مبلغ:
- **مبلغ هر قسط** (مساوی)
- **مبلغ کل** (تقسیم مساوی؛ باقیمانده تقسیم به قسط آخر اضافه می‌شود)
- **مبالغ متفاوت**: هر مبلغ در یک خط، یا با `+`؛ برای تکرار از `*`:
  ```
  5000000*6
  3000000*6
  ```

**🔁 دوره‌ای** — هفتگی، ماهانه، هر ۲/۳/۶ ماه یا سالانه؛ بدون پایان، تا وقتی متوقفش کنید.

**📌 یک‌باره** — یک پرداخت با تاریخ مشخص.

## پرداخت
- **✅ پرداخت شد** روی یادآوری یا لیست ماه
- **💵 پرداخت جزئی**: مبلغ را وارد کنید؛ وضعیت قسط «جزئی» می‌شود
- **↩️ لغو آخرین پرداخت**
- **💰 تسویه کامل**: همه اقساط باقیمانده پرداخت‌شده ثبت می‌شوند
- ویرایش مبلغ یا تاریخ یک قسط خاص، از لیست اقساط

## اقساط مشترک
هنگام افزودن، «مشترک با …» و درصد سهم خودتان را انتخاب کنید. هر دو نفر مورد را می‌بینند، یادآوری سهم خودشان را می‌گیرند و هر پرداخت به طرف مقابل اطلاع داده می‌شود. ویرایش و حذف فقط برای سازنده است.

## یادآوری‌ها (⚙️ تنظیمات)
- زمان: ۷، ۵، ۳، ۲، ۱ روز قبل و روز سررسید (چند انتخابی)
- ساعت ارسال (وقت تهران)
- یادآوری روزانه معوقه‌ها تا ثبت پرداخت
- خلاصه پرداخت‌های ماه در روزهای اول هر ماه
- پرسش «واریز شد؟» برای درآمدها
- 🧪 تست یادآوری: ارسال فوری یادآوری‌های امروز

## درآمد و برنامه
1. درآمدهای ثابت را با مبلغ و **روز واریز** ثبت کنید (مثلاً حقوق، روز ۲۵ام؛ اجاره، روز ۵ام).
2. هر واریز، اقساطی را پوشش می‌دهد که **از روز همان واریز تا واریز بعدیِ همان درآمد** سررسید می‌شوند.
3. **حالت خودکار**: هر قسط به آخرین واریزی قبل از سررسیدش که ظرفیت دارد وصل می‌شود.
   **حالت دستی**: فقط اقساطی که خودتان وصل کرده‌اید (🔗 تخصیص) در برنامه می‌آیند. تخصیص دستی در هر دو حالت اولویت دارد.
4. روز واریز، ربات می‌پرسد «واریز شد؟» (تا ۱۰ روز، روزی یک بار). بعد از تأیید — یا وارد کردن مبلغ واقعی — فهرست «از این واریز کنار بگذارید» و مبلغ قابل خرج را می‌فرستد.
5. **📊 آمار درآمدها**: مانده آزاد هر درآمد، اقساط متصل، وضعیت واریز و کنار گذاشتن، و **🔮 پیش‌بینی** ۳/۶/۱۲ ماه.

## بودجه دسته‌ها
در 🗂 دسته‌بندی‌ها برای هر دسته سقف ماهانه بگذارید. اگر پرداختی‌های ماه از سقف بگذرد، یک بار در همان ماه هشدار می‌گیرید.

## مدیریت (فقط مدیر)
- تأیید/رد درخواست دسترسی کاربران جدید، افزودن دستی با شناسه، حذف دسترسی
- آمار کلی و زمان آخرین اجرای کرون و بکاپ
- 💾 بکاپ فوری (فایل `.sql.gz` در چت)
- 📣 پیام همگانی
