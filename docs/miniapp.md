# مینی‌اپ

نسخه گرافیکی ربات که داخل خود تلگرام باز می‌شود. همان داده‌های ربات را نشان می‌دهد؛ هر تغییری در یکی، در دیگری هم دیده می‌شود.

## باز کردن
- دکمه منوی **«اپ اقساط»** کنار کادر پیام (با اولین پیام به ربات، خودکار تنظیم می‌شود)
- دکمه **«📱 باز کردن اپ»** بعد از `/start`

**آدرس مینی‌اپ** (اگر خواستید در BotFather هم ثبت کنید):
```
https://example.com/aqsat-bot/app/
```
یعنی `base_url` + `/app/` — حتماً با `/` در انتها.
در BotFather: `/mybots` ← ربات ← **Bot Settings** ← **Menu Button** یا **Configure Mini App**.

## صفحه‌ها

| صفحه | محتوا |
|---|---|
| **خانه** | پرسش «واریز شد؟»، هشدار معوقه، **آزادِ واقعی ماه**، مانده آزاد هر دریافتی، بدهی باقیمانده و تاریخ آزادی از بدهی، اقساط ماه جاری با دریافتی متصل؛ از ۲۰ام هر ماه، اقساط ماه بعد هم |
| **اقساط** | فیلتر (وام، دوره‌ای، یک‌باره، معوقه، بایگانی)، پیشرفت وام‌ها، **کشیدن کارت به چپ برای ثبت پرداخت** |
| **جزئیات** | آمار وام، پرداخت بعدی، منبع پرداخت، تسویه/توقف/ویرایش/حذف، لیست اقساط با ویرایش مبلغ و تاریخ و لغو پرداخت |
| **درآمد و برنامه** | حالت تخصیص، تقسیم هر دریافتی بین اقساط، **کشیدن و رها کردن اقساط بین دریافتی‌ها**، ثبت واریز، «کنار گذاشتم»، مبلغ واقعی ماه، مدیریت درآمدها |
| **گزارش‌ها** | این ماه (شاخص‌ها، دسته‌ها و بودجه، تقسیم دریافتی‌ها، بزرگ‌ترین تعهدها)، سالانه، آینده (پیش‌بینی ۶ ماه، پرفشارترین ماه، مسیر آزادی از بدهی)، خروجی اکسل، ارسال خلاصه در ربات |
| **تقویم** | تقویم شمسی با رنگ‌بندی دریافتی/در انتظار/پرداخت‌شده/معوقه و جزئیات هر روز |
| **افزودن / ویرایش** | فرم کامل با انتخابگر تاریخ شمسی، مبالغ متفاوت، سهم مشترک، انتخاب دریافتی منبع و پیش‌نمایش |
| **تنظیمات** | یادآوری‌ها، دسته‌بندی‌ها و سقف بودجه |

ویژگی‌های تلگرامی: تم روشن/تاریک هماهنگ با تلگرام، لرزش (Haptic)، دکمه‌های Back و Main خود تلگرام، غیرفعال بودن بستن تصادفی با کشیدن به پایین.

## توسعه

سورس در پوشه `miniapp/` است (Vue 3 + Vite، بدون فریم‌ورک CSS).

```bash
cd miniapp
npm install
npm run build      # خروجی در ../app
```

- کتابخانه وب‌اپ تلگرام (`public/telegram-web-app.js`) به‌صورت محلی همراه اپ است تا به دسترسی به telegram.org وابسته نباشد.
- مسیرها با hash router هستند؛ پارامترهای راه‌اندازی تلگرام (`#tgWebAppData=…`) قبل از راه‌اندازی روتر پاک می‌شوند.
- برای تست در مرورگر می‌توانید یک `initData` امضاشده با توکن ربات را با پارامتر `?dev_init=` به آدرس اضافه کنید (سرور همان امضا را بررسی می‌کند).

| فایل | نقش |
|---|---|
| `src/api.js` | فراخوانی `../api.php` با هدر `X-Init-Data` |
| `src/store.js` | داده‌های مشترک، Toast و `act()` برای عملیات تغییردهنده |
| `src/jalali.js` / `src/fmt.js` | تقویم شمسی و قالب‌بندی اعداد/مبالغ |
| `src/tg.js` | ارتباط با Telegram WebApp (Haptic، دکمه‌ها، تم) |
| `src/views/*` | صفحه‌ها |
| `src/components/*` | اجزای مشترک (Sheet، Ring، DatePicker، Swipe، …) |
