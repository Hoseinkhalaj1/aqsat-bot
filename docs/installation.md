# نصب و بروزرسانی

## پیش‌نیازها
- هاست سی‌پنل **خارج از ایران** (برای دسترسی سرور به API تلگرام)
- PHP **8.0+** با افزونه‌های `pdo_mysql`، `curl`، `mbstring`، `zip` (برای خروجی اکسل) و `zlib` (برای بکاپ)
- MySQL 5.7+ یا MariaDB 10.3+
- دامنه یا ساب‌دامین با **SSL** (AutoSSL سی‌پنل کافی است). وبهوک و مینی‌اپ تلگرام فقط روی HTTPS کار می‌کنند.

## نصب گام‌به‌گام

### ۱. ساخت ربات
در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزنید و **توکن** را بردارید.
شناسه عددی خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید.

### ۲. دیتابیس
در سی‌پنل، بخش **MySQL Databases**:
1. یک دیتابیس بسازید (مثلاً `cpuser_aqsat`).
2. یک یوزر با رمز قوی بسازید.
3. یوزر را با دسترسی **ALL PRIVILEGES** به دیتابیس وصل کنید.

### ۳. آپلود
همه فایل‌های مخزن **به‌جز پوشه `miniapp`** را در پوشه‌ای زیر `public_html` آپلود کنید، مثلاً `public_html/aqsat-bot`.
(پوشه `app` همان مینی‌اپ ساخته‌شده است و لازم است.)

### ۴. تنظیمات
`config.sample.php` را به `config.php` تغییر نام دهید و پر کنید:

| کلید | توضیح |
|---|---|
| `bot_token` | توکن BotFather |
| `admin_ids` | آرایه شناسه‌های عددی مدیر، مثلاً `[123456789]` |
| `base_url` | آدرس پوشه ربات با https، مثلاً `https://example.com/aqsat-bot` |
| `webhook_secret` | رشته تصادفی ۱۶+ کاراکتری (حروف انگلیسی، عدد، `-`، `_`) |
| `cron_key` | رشته تصادفی دیگر ۱۶+ کاراکتری |
| `db` | اطلاعات دیتابیس |
| `timezone` | پیش‌فرض `Asia/Tehran` |
| `backup_hour` / `backup_keep` / `backup_to_telegram` | ساعت بکاپ روزانه، تعداد نسخه‌های نگهداری‌شده، ارسال بکاپ برای مدیر |

> ساخت رشته تصادفی: `openssl rand -hex 16` یا هر تولیدکننده رمز.
> با مقدار پیش‌فرض `CHANGE-ME`، وبهوک، کرون و نصب عمداً کار نمی‌کنند.

### ۵. اجرای نصب
در مرورگر باز کنید:
```
https://example.com/aqsat-bot/install.php?key=CRON_KEY
```
همه موارد باید ✅ باشند (ساخت جداول، ثبت مدیر، تنظیم وبهوک). سپس **`install.php` را از هاست حذف کنید.**

### ۶. کرون جاب
در سی‌پنل، بخش **Cron Jobs**، با زمان‌بندی `*/15 * * * *`:
```
/usr/local/bin/php /home/CPANEL_USER/public_html/aqsat-bot/cron.php >/dev/null 2>&1
```
اگر php-cli در دسترس نبود:
```
wget -q -O /dev/null "https://example.com/aqsat-bot/cron.php?key=CRON_KEY"
```
کرون این کارها را انجام می‌دهد: ارسال یادآوری‌ها در ساعت تنظیم‌شده هر کاربر، ساخت سررسیدهای بعدی پرداخت‌های دوره‌ای، خلاصه اول ماه، پرسش واریز درآمد و بکاپ روزانه.

### ۷. شروع
در تلگرام به ربات `/start` بدهید. کاربران دیگر هم `/start` بزنند؛ درخواستشان برای مدیر می‌آید و با دکمه **تأیید** فعال می‌شوند (یا از پنل مدیریت ← افزودن کاربر).

دکمه منوی **«اپ اقساط»** (مینی‌اپ) با اولین پیام، خودکار تنظیم می‌شود.

## بروزرسانی
1. از دیتابیس و `config.php` بکاپ بگیرید.
2. همه فایل‌ها را **به‌جز `config.php`** جایگزین کنید (پوشه `app` را کامل جایگزین کنید).
3. تغییرات دیتابیس در اولین درخواست، خودکار اعمال می‌شود.

> از نسخه 1.3 به بعد، `webhook_secret` و `cron_key` باید ۱۶+ کاراکتر و غیر از `CHANGE-ME` باشند. اگر مقدارشان را عوض کردید، یک بار `install.php` را دوباره اجرا کنید تا وبهوک با رمز جدید ثبت شود (و بعد حذفش کنید).

## بازگردانی بکاپ
فایل `aqsat-backup-*.sql.gz` (پوشه `backups` یا فایلی که ربات فرستاده) را در **phpMyAdmin ← Import** وارد کنید.

## رفع اشکال

| مشکل | بررسی |
|---|---|
| ربات جواب نمی‌دهد | `https://api.telegram.org/bot<TOKEN>/getWebhookInfo` را باز کنید؛ `last_error_message` را ببینید. `webhook_secret` و SSL را چک کنید و `install.php` را دوباره اجرا کنید. |
| یادآوری نمی‌آید | در ربات: 🛠 مدیریت ← آمار ← «آخرین اجرای کرون». اگر خالی است، Cron Job را بررسی کنید. |
| مینی‌اپ صفحه خالی/سیاه | آدرس باید با `/` تمام شود: `…/app/`. پوشه `app` را کامل جایگزین کنید و تلگرام را کامل ببندید و باز کنید. |
| «این اپ فقط داخل تلگرام باز می‌شود» | اپ را از دکمه منوی ربات باز کنید، نه مرورگر. |
| «نشست منقضی شده» | اپ را ببندید و دوباره باز کنید (اعتبار ورود ۲۴ ساعت است). |
| خروجی اکسل CSV است | افزونه `zip` در PHP فعال نیست (از MultiPHP Extensions سی‌پنل فعال کنید). |
| خطاهای دیگر | فایل `logs/error.log` |
